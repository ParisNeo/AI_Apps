About VueNotesPro v1.0

Author: ParisNeo

Category: Productivity

Description: A feature-rich, responsive note-taking web application built with Vue.js and Tailwind CSS. Supports categories, subcategories, Markdown rendering, import/export, social sharing, and client-side encryption for secret notes. All data is stored locally using IndexedDB.

Model used for assistance: Claude 3 Opus

Disclaimer: This application stores data, including potentially encrypted secret notes, locally in your browser's IndexedDB. The master key for secret notes is NOT stored. Ensure you remember your master key, as there is no recovery mechanism. Use at your own risk.

Features:

  • Categories & Subcategories
  • Markdown input, HTML rendering
  • Import/Export notes (JSON)
  • Social Sharing (basic text sharing)
  • Secret notes with AES-256 encryption (master key not stored)
  • Data stored in IndexedDB
  • Easy copy/paste with SVG icons
  • Responsive design for PC, phone, and tablet
  • Light/Dark theme with improved contrasts
  • Floating Action Button for new notes

Keyboard Shortcuts (in note form):

  • Ctrl+S or Cmd+S: Save note
