    How to Play

    Stop invaders from reaching the end of the path!

    • Profiles: Create or select a profile to save your progress and high scores.
    • Towers: Select towers from the panel, then click on empty green squares to place them. They cost gold.
    • Gold: Earn by defeating invaders and clearing waves/levels.
    • Lives: Start with 20. Lose one for each escaped invader. 0 lives = Game Over.
    • Waves: Click "Start Wave" to begin. Survive all waves in a level to advance.
    • Unlocks: Better towers unlock as you reach higher levels!
    • Tower Types: Turret (Basic), Cannon (High Dmg, Lvl 4), Freezer (Slow, Lvl 7).
    • Level Reset: At the start of each new level, existing towers are sold (full refund), letting you re-strategize.
    • Progress: Your game (level, gold, lives, score) is saved automatically for the active profile after each wave and level.
